# Privacy Policy — Marbles

**Last updated: 2026-09-18**

Marbles does not collect, store, or transmit any personal data.

- The app has no internet access permission and makes no network requests.
- It uses your device's tilt/gravity sensor only to control gameplay in
  real time. That sensor data is never stored, logged, or transmitted
  anywhere — it exists only for the current moment of gameplay.
- There are no accounts, no analytics, no advertising, and no
  third-party SDKs of any kind.
- No data is shared with anyone, because none is collected in the first
  place.

If this policy ever changes (for example, if a future version adds
online features), this page will be updated to reflect that before such
a version is released.

Questions? Open an issue at
https://github.com/chucksmarthouse/marbles/issues
