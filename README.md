# Marbles

A tilt-controlled marble maze game for Android. Tilt your phone to roll the
marble through the maze from the start to the goal, avoiding the holes along
the way.

**This is a beta test build.** It's an early, actively-changing version used
for testing — expect rough edges, and expect it to change from one build to
the next.

## How to play

- Tilt your phone to roll the yellow marble through the maze.
- Reach the green circle to win — tap the screen to play again.
- Avoid the red holes — falling in sends the marble back to the start.

## Installing (sideload)

This isn't on the Play Store — you install the APK directly ("sideloading").

1. On your Android phone, open this link and download the APK:
   **https://github.com/chucksmarthouse/marbles/releases/latest/download/marbles-debug.apk**
   (This link always points to the newest build — bookmark it to get updates
   later.)
2. Open the downloaded file (from your notification shade, or your
   **Files** app's Downloads folder).
3. If Android blocks the install, it'll prompt you to allow installs from
   whichever app opened the file (Files, Chrome, etc.) — tap through to that
   setting and allow it, then go back and try installing again.
4. If Google Play Protect warns that it doesn't recognize the app, tap
   **Install anyway** / **Install without scanning** — this is expected for
   an app distributed outside the Play Store.
5. Open **Marbles** from your app drawer.

To update later, just revisit the same link above and reinstall — no need to
uninstall the old version first.

## Requirements

- Android 8.0 (API 26) or newer
- A device with an accelerometer/gravity sensor (i.e., basically any phone)
